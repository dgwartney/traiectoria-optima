The Problem

Given the world airline network, find the cheapest / shortest / fewest-stop route between two airports — and show how informed search (A*) expands fewer nodes than uninformed search (BFS / Dijkstra) while returning the same answer.

A* with a Haversine Heuristic

f(n) = g(n) + h(n), where h(n) is the great-circle distance from n to the goal.

  • Admissible: no flight path is shorter than the great-circle distance, so h never overestimates.
  • Consistent: h obeys the triangle inequality on the sphere.
